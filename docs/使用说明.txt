科研高清导出 v1.2 — Windows 桌面 Microsoft PowerPoint

交付状态
本包已包含本机 PowerPoint 16.0 生成的 build/ResearchExport.ppam 及完整源码；加载项未签名。目标为支持 VBA 的 Windows 桌面 PowerPoint（建议 2016/2019/2021/Microsoft 365）；不支持网页版、Mac、WPS。未验证上述各版本。无需 Python、管理员权限或每次打开 VBA 编辑器。首次构建需要 Windows PowerShell 5.1、桌面 PowerPoint 及其 VBA 组件。

一、首次生成和安装

已有 PPAM 的推荐安装方式：在本文件夹打开 PowerShell，运行：
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Addin.ps1
此方式无需启用 VBA 工程访问。新电脑首次使用请运行安装脚本。
仅当修改 VBA 源码或需要重新构建时，才执行下面的构建步骤。

1. 解压整个文件夹到本地固定位置。先关闭所有 PowerPoint 窗口并保存工作。
2. PowerPoint → 文件 → 选项 → 信任中心 → 信任中心设置 → 宏设置，临时勾选“信任对 VBA 工程对象模型的访问”。不要选择“启用所有宏”。关闭 PowerPoint。
3. 在解压后的 ResearchExport 文件夹打开 Windows PowerShell，运行：
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Build-Addin.ps1 -Install
   此命令和运行时 PNG 组件均仅对各自 PowerShell 进程使用 Bypass，不修改系统执行策略。单位组策略仍可能阻止运行；遇到限制请联系管理员，勿绕过单位政策。
4. 成功后文件在 %APPDATA%\ResearchExport；重启 PowerPoint，检查“科研高清导出”。源文件夹的 build 子文件夹保留生成的 PPAM。
5. 立即取消第 2 步的 VBA 工程访问。此权限只在构建时使用，日常导出无需开启。
6. 未签名加载项可能被阻止。仅在审查并信任本源码后，依本单位政策信任单独的 %APPDATA%\ResearchExport 文件夹，或用本单位证书签署 VBA 工程。不要把下载目录或整个用户目录加入信任位置，不要全局降低宏安全级别。互联网下载文件如带“解除锁定”，仅对确认可信的本包文件使用。签名需要单位证书，包内无证书。

也可不加 -Install，仅生成，再用 PowerPoint → 文件 → 选项 → 加载项 → 管理“PowerPoint 加载项”→ 转到 → 添加，选择 build\ResearchExport.ppam。构建脚本仍会安装 PNG 组件。
重新构建：备份并删除源码目录 build\ResearchExport.ppam 后再运行。更新前在 PowerPoint 中卸载旧加载项并关闭 PowerPoint。脚本不会关闭你的其他演示文稿，也不会强制结束 PowerPoint 进程。

二、日常使用
打开任意 PPT，功能区选择 300/600/900/1200 或自定义 36–2400 DPI；默认 600，每次重启恢复默认。当前选择会在导出确认框显示。
“当前幻灯片”：使用原幻灯片宽高，保留原背景。
“选中对象／组合（白底）”：先在普通视图选中对象（退出文字编辑），在粘贴前先设定临时无窗口演示文稿的画布尺寸，再复制、组合并移到原点；保持对象原尺寸，以 Slide.Export 显式像素渲染画布，再按选区像素框裁切白底 PNG（不缩放采样）。不会保存或修改原稿，会覆盖剪贴板。建议先将最终科研组图组合再导出。
“选区透明 PNG（实验）”：对同样的临时选区使用 Shape.Export。PNG 保留其输出 alpha，不做抠白或重采样。校验输出像素及 alpha 通道；失败则拒绝保存，可改用白底按钮。具备 alpha 通道不等于每处背景必然透明；不透明矩形、照片及填充仍不透明。不要把白底幻灯片导出当作透明导出。
选择保存位置，扩展名不是 .png 时会追加 .png。同名文件再次确认覆盖。文件只在导出校验通过后替换。

新增：定尺寸裁剪（v1.2）
1. 在“科研高清导出”中点击“插入裁剪框…”，输入输出宽高（毫米），例如55和50。
2. 页面中出现红色虚线框。只移动框，使其罩住需要的内容，无须拆开或裁剪科研组合。如需保持刚才输入的物理尺寸，请拖框边移动，不要拖角点改变大小；也可在“形状格式 → 大小”中精确改宽高。
3. 单独选中裁剪框，选择 DPI，点击“按裁剪框导出”，确认宽高/像素后保存PNG。
4. 55×50 mm、600 DPI仍输出1299×1181像素。框内全部可见内容和原幻灯片背景进入输出；框外裁掉，不缩放组图。此路径不承诺透明背景。
限制：裁剪框必须完整位于幻灯片内，不能旋转，也不要把它与其他内容组合。可以有多个裁剪框，导出时只选中一个；所有由本功能插入且未组合的裁剪框都会在临时输出副本中删除。原稿中的框会保留供重复使用。
注意：裁剪框是普通幻灯片形状；如果使用原来的“当前幻灯片/选中对象”导出，它仍按原有行为参与输出。用完不需要时可选中框按Delete删除；不会删除下面的组图。
裁剪区域取自整张幻灯片，并非仅取某个组合。如果框内有其他遮挡物也会输出，请先调整其可见性或位置。高DPI大页面需要先渲染整个页面，受原有像素上限限制。

三、尺寸和清晰度
像素 = floor(点数 / 72 × DPI + 0.5)，毫米 = 点数 / 72 × 25.4。
55 mm × 50 mm，600 DPI → 1299 × 1181 像素。
pHYs 使用整数 pixels/metre：600 DPI → 23622 px/m → 599.9988 DPI，软件显示 600 属正常舍入。
如需上述 TOC，先在“设计 → 幻灯片大小 → 自定义”中设置宽 5.5 cm、高 5.0 cm，再导出当前页。选区则按实际对象的组合框大小计算，不会自动改成 TOC 尺寸。
导出后不要随意在 Word/排版软件改变物理宽高，否则有效 DPI 会改变。
本工具不读、不写 ExportBitmapResolution；主要路径调用 Slide.Export(file,"PNG",pixelWidth,pixelHeight)，再检查实际 PNG 尺寸。PowerPoint 限制或异常不做静默重采样。
边长超过 32767 或总像素超过一亿会被本工具拒绝，更低版本/内存不足可能在更小尺寸失败。

原始照片的有效分辨率取决于原图像素 ÷ 最终放置尺寸（英寸）。例如 1000 px 图片放到 55 mm 宽，最多约 462 DPI 的原始细节；输出 1200 DPI 仍不能创造信息。请保留高分辨率原始图，PowerPoint 设置“不压缩文件中的图像/高保真”只能帮助避免后续损失，不能恢复已压缩内容。本版不自动计算每张图片的有效 DPI，尤其裁剪、组合和已有压缩情况下，需核对原文件。

四、边界与验收
选区依赖 PowerPoint 对象/组合的 Width/Height；旋转单对象、阴影、发光、线端、超出框的文字可能裁切，嵌入 OLE、视频、链接图片和特殊字体可能改变外观。建议把旋转对象先组合，并在周围增加必要留白，导出后逐项核对。小尺寸选区不再放大对象，而是渲染后裁切；输出像素按原物理尺寸和 DPI 计算。渲染画布至少为原幻灯片尺寸，高 DPI 大页面可能触发画布像素上限，此时请降低 DPI 或在较小页面制作组图。
本版暂不提供 TIFF/SVG，避免格式、透明度和字体兼容性承诺。
异常和取消会关闭临时演示文稿，删除中间 PNG；校验失败日志保留在提示的 TEMP 路径。原文件不改动；目标文件在校验失败时保留。崩溃/强制终止时可能留下临时文件，可关闭 PowerPoint 后清理 TEMP 中 ResearchExport- 前缀文件。

本地验收（首次用于投稿前完成）
□ 安装后重启 PowerPoint，新建另一份 PPT 仍有功能区。
□ 55×50 mm 页面分别导出 300/600/900/1200 DPI，600 得到 1299×1181。
□ 图像查看器或 ImageMagick identify 检查尺寸和 DPI；600 的 pHYs 为 23622 px/m。
□ 用文字、线条、透明形状、照片构造组合，对比白底/透明导出，用棋盘背景查看 alpha 和边缘。
□ 检查旋转对象、阴影、特殊字体、裁剪照片和小于 25.4 mm 的选区。
□ 取消保存、拒绝覆盖、错误路径及超大像素后，原稿和已有目标文件不变，无残留临时演示文稿。
□ 保存并重开原 PPT，确认没有被加入临时对象。

五、卸载
PowerPoint → 文件 → 选项 → 加载项 → 管理 PowerPoint 加载项 → 转到，取消并移除 ResearchExport。关闭 PowerPoint 后删除 %APPDATA%\ResearchExport 内 ResearchExport.ppam 和 Finalize-Png.ps1。如设置过该文件夹的信任位置，同时移除。删除解压源码目录和 build 不影响其他 PPT。
